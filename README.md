# mnky-studio-pins

Public media for the MNKY Studio Pinterest account (Etsy shop MnkyStudioCo): only the finished pin images and
videos, so Buffer can fetch them by URL (Buffer's API has no file upload). Nothing else lives here.

Source, generator and plan: private repo `etsy-mnky` (`marketing/pinterest/`, `docs/PINTEREST.md`).
Files are copied here by `python -m tools.buffer_api fill` in that repo. Public on purpose (Miguel, 04/10/2026):
the same images are public on Pinterest.
